3. Git 与 Worktree 模型

所有 worktree 在仓库根物理平铺，无中间目录层、无嵌套。

图 3 · Worktree 平铺布局与分支拓扑

.gitignore 双层防御

*              # 全忽略
!*/            # 保留目录遍历
!.gitignore
!README.md
/*/            # 屏蔽所有第一层子目录（worktree 都在第一层）
即使误操作 git add .，workspace 分支也只会跟踪 2 个文件，worktree 完全不被污染。

11. 风险与演进

观测到的风险点

风险证据影响建议
3 个 Application OutOfSyncanspire-open-admin-uat、anspire-open-man-bootstrap、anspire-wb365-bridge-uat配置漂移排查手动改动；开 prune 前确认无残留
prune: false 全局所有 Application syncPolicy删除资源后集群残留累积非关键资源改 prune: true
2 条 Ingress 未配 TLSaisearch-api、aisearch-global-apiHTTP 明文流量补齐 tls 段
Runner privileged + docker.sockgitlab-runner-config ConfigMap容器逃逸风险迁移 Kaniko / rootless BuildKit
Runner 缓存凭据明文MinIO AccessKey=admin 硬编码凭据泄露改用 Secret 引用
中间件无资源限制MySQL/Postgres/Qdrant 未显式设 limit单 Pod 可能耗尽集群资源补充 requests/limits
单副本业务ArgoCD 托管应用多为 replicas=1无高可用关键服务提升副本 + PDB
资源未隔离中间件与业务同集群混部资源争抢nodeAffinity / taint 隔离

演进建议

01 · ApplicationSet
自动发现 Application
用 Git Generator 自动发现 argocd/applications/*.yaml，消除手写 bootstrap。
02 · 环境目录
deploy 分支拆环境
overlays/uat 之外补齐 overlays/production，隔离发布路径。
03 · 镜像 tag
改为 commit SHA 短码
uat-20261016-80 无法定位 commit，建议 uat-20261016-a1b2c3d。
04 · Ingress
模板化
Kustomize components/ 抽出通用 Ingress 模板，统一 TLS 与注解。
05 · Runner
安全加固
迁移 Kaniko 或 rootless BuildKit，移除 privileged 与 docker.sock 依赖。
06 · 可观测性
补齐监控
Traefik metrics（9100）接入 Prometheus + Grafana；Langfuse 用于 LLM 链路追踪。
