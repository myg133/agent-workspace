# 安全审查清单

## 依赖安全

- [ ] 依赖版本已更新到安全版本
- [ ] 没有已知漏洞的依赖（检查 CVE 数据库）
- [ ] 没有引入恶意包

## API 安全

- [ ] 认证机制已实现
- [ ] 授权检查已实现
- [ ] 速率限制已考虑
- [ ] 请求体大小限制已考虑
- [ ] 输入校验已实现
- [ ] 输出编码已实现（防止 XSS）

## 数据安全

- [ ] 敏感数据已加密存储
- [ ] 传输层使用 HTTPS
- [ ] 数据库查询使用参数化查询（防止 SQL 注入）
- [ ] 日志中不包含敏感数据

## 配置安全

- [ ] 密钥和密码不在代码中硬编码
- [ ] 环境变量用于配置
- [ ] 默认配置安全（不暴露调试接口）
- [ ] CORS 配置正确

## 运维安全

- [ ] 健康检查端点不暴露敏感信息
- [ ] 错误信息不暴露内部实现细节
- [ ] 容器不以 root 用户运行
- [ ] 容器镜像扫描无漏洞
